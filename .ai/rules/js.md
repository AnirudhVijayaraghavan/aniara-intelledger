# Js

## Aniara ledger visual language
Use the Aniara Intelledger design tokens and ledger-serif UI language: teal primary, mint secondary, restrained orange accents, dense operational layouts, and rounded-md-or-smaller panels. Financial screens should feel calm and institutional; avoid marketing filler, decorative gradients, generic SaaS styling, and language implying automated trades.
