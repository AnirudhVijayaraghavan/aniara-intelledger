# IntelLedger Product Design

Use this skill with `inertia-react-development` and `tailwindcss-development` for frontend work.

## Design Direction

- Build light, premium fintech interfaces.
- The visual tone should sit between a modern investing product and a disciplined financial publication.
- Prefer clarity, restraint, and polish over novelty.

## Palette

Use these colors as the default house palette:

- `#ff9f1c`
- `#ffbf69`
- `#ffffff`
- `#cbf3f0`
- `#2ec4b6`

Supporting neutrals should stay light and warm-cool, not gray-heavy or muddy.

## Typography

- Use a serif headline paired with a clean sans-serif UI font.
- Serif is for major headings and hero statements.
- Sans is for controls, labels, navigation, and body copy.
- Typography should feel editorial, not startup-generic.

## Layout Rules

- Prefer calm, readable layouts with strong spacing and clear hierarchy.
- Use simple section structures over busy dashboards.
- Cards should be restrained: soft borders, light backgrounds, subtle shadows.
- Backgrounds should feel intentional: soft gradients or light atmospheric color, not flat white by default.
- Keep mobile behavior clean; avoid layouts that only work on desktop.

## Component Guidance

- Buttons should be rounded and clear, with one obvious primary action.
- Navigation should be sparse and easy to scan.
- Summary panels should show structure, not fake financial precision.
- Tables, cards, and stats should feel product-grade, not template-like.

## Copy Rules

- Keep copy short, direct, and professional.
- Do not write cringey marketing language.
- Do not invent fake portfolio values, fake performance numbers, or synthetic financial detail unless the user explicitly wants placeholders.
- Prefer neutral labels like `Coverage`, `Cash flow`, `Research`, `Daily brief`, `Net worth`.
- Avoid inflated claims like "world-class", "revolutionary", "game-changing", or similar filler on the page itself.

## Anti-Patterns

- No dark-heavy default aesthetic unless the existing screen already requires it.
- No generic SaaS hero copy.
- No noisy gradients, glass overload, or excessive glow.
- No dense clusters of decorative widgets that do not carry product meaning.
- No fake terminal/trading-screen aesthetics.

## Working Style

- Before introducing a new pattern, check whether an existing page or component can carry the same design language.
- When redesigning a screen, change structure when needed instead of only swapping colors.
- Keep content grounded in the actual product: portfolio consolidation, net worth, expense review, cash flow, and research.
